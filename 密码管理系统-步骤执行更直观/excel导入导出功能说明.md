# Excel导入导出功能说明

## 功能简介

密码管理系统现已支持Excel格式的密码记录导入导出功能，方便用户批量管理密码数据。

## 依赖说明

Excel导入导出功能依赖以下Python库：
- pandas：数据处理库
- openpyxl：Excel文件读写库
- xlsxwriter：Excel文件格式化库

这些依赖已添加到requirements.txt中，安装系统时会自动安装。

## 功能入口

在主界面菜单栏的"文件"菜单下的"Excel管理"子菜单中，可以找到：
- 从Excel导入：导入Excel文件中的密码记录
- 导出到Excel：将当前人员的密码记录导出为Excel文件
- 多人员导出：将多个人员的密码记录导出到同一个Excel文件的不同工作表中（管理员功能）

## 导出功能

### 单人员导出
1. 在主界面选择需要导出密码的人员
2. 点击菜单"文件" -> "Excel管理" -> "导出到Excel"
3. 在弹出的对话框中选择导出选项（可以选择是否隐藏密码）
4. 点击"导出"按钮
5. 选择保存位置后，系统将生成格式化的Excel文件

导出的Excel文件具有以下特点：
- 表格式布局，清晰展示所有记录
- 必填字段以粗体显示
- 冻结首行，方便查看
- 带有导出信息（导出时间、人员）

### 多人员导出
1. 点击菜单"文件" -> "Excel管理" -> "多人员导出"（仅管理员可用）
2. 在弹出的对话框中：
   - 选择要导出的人员（可多选）
   - 可以选择是否隐藏密码
   - 选择保存文件的位置和名称
3. 点击"导出"按钮开始导出

多人员导出特点：
- 每个人员的密码记录将存储在单独的工作表中
- 第一个工作表为导出摘要，包含导出统计信息
- 所有工作表均采用统一的格式和样式
- 自动处理工作表名称过长的情况
- 适合管理员进行密码记录的统一管理和备份

## 导入功能

1. 在主界面选择需要导入密码的人员
2. 点击菜单"文件" -> "Excel管理" -> "从Excel导入"
3. 如果没有模板文件，可以点击"下载模板"生成标准格式的Excel模板
4. 在导入对话框中选择导入模式：
   - 追加模式：将新记录添加到现有记录后
   - 替换模式：删除所有现有记录，只保留导入的记录
5. 点击"选择文件"按钮，选择要导入的Excel文件
6. 点击"导入"按钮执行导入操作

## 导入文件格式要求

导入的Excel文件必须符合以下格式要求：
1. 必须包含所有必要的列（项目名称、功能、IP地址、账户、密码、所在区域、网络类型、其他账号）
2. 必填字段（项目名称、IP地址、账户、密码）不能为空
3. 列名要与系统定义的名称一致（建议使用系统提供的模板）

## 注意事项

1. 导出时可以选择是否隐藏密码，以增强安全性
2. 导入时请确保数据格式正确，尤其是必填字段
3. 替换模式会删除所有现有数据，请谨慎使用
4. 敏感信息导出后的Excel文件请妥善保管
5. 多人员导出功能仅限管理员使用，普通用户无法访问

## 审计日志

系统会记录所有导入导出操作，包括：
- 操作类型（导入/导出）
- 操作时间
- 操作人员
- 操作结果
- 操作详情（文件名、记录数量等）

您可以通过"工具" -> "日志查看" -> "审计日志查看"查看这些操作记录。
