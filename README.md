# 密码管理系统

一个安全的、功能丰富的密码管理系统，帮助用户集中管理各类账号和密码信息，支持远程服务器密码更新。

## 主要功能

- **密码记录管理**：添加、查看、编辑和删除密码记录
- **用户身份认证**：用户注册、登录和记住密码功能
- **数据安全保障**：基于AES-128-CBC算法加密存储所有敏感数据
- **按所有者分类**：支持按所有者分类管理密码记录
- **密码搜索**：支持通过关键词搜索密码记录
- **密码自动生成**：提供随机密码生成功能
- **远程密码更新**：支持SSH远程服务器密码更新
- **SSH操作日志**：提供SSH操作日志查看和分析功能

## 界面展示

系统包含两个主要界面：
1. **登录界面**：用户认证入口
2. **密码管理界面**：管理密码记录的主界面

密码管理界面采用表格方式展示密码记录，支持排序、搜索和过滤功能。

## 系统架构

系统采用模块化设计，主要模块包括：

- **用户管理**：处理用户认证
- **数据库**：提供数据持久化
- **加密**：实现数据加密解密
- **密码管理**：处理密码记录操作
- **SSH操作**：提供远程服务器操作
- **UI组件**：提供统一界面元素

## 安装说明

### 系统要求

- Python 3.8+
- Windows 7/10/11 或 Linux/macOS

### 安装步骤

1. 克隆仓库或下载源代码：
   ```
   git clone https://github.com/your-repo/password-manager.git
   cd password-manager
   ```

2. 安装依赖包：
   ```
   pip install -r requirements.txt
   ```

3. 运行程序：
   ```
   # Windows
   python run.py
   
   # Linux/macOS
   python3 run.py
   ```

## 使用指南

### 用户注册与登录

1. 首次使用需要注册新用户
2. 登录后可选择"记住密码"功能
3. 登录成功后进入密码管理主界面

### 密码记录管理

1. **添加密码**：点击"添加"按钮，填写表单
2. **编辑密码**：双击需要编辑的记录或选中后点击"编辑"按钮
3. **删除密码**：选中记录后点击"删除"按钮或使用右键菜单
4. **搜索密码**：在搜索框中输入关键词，系统会实时过滤显示结果

### 远程密码更新

1. 选择需要更新的服务器密码记录
2. 点击"更新服务器密码"按钮
3. 输入新密码
4. 系统会自动尝试SSH连接到服务器并更新密码

### SSH日志查看

1. 点击"查看SSH日志"按钮
2. 可以浏览最近的SSH操作记录
3. 支持过滤和搜索功能

## 数据存储

系统数据存储在`data`目录下的JSON文件中：

- `users.json`：用户信息
- `passwords.json`：密码记录
- `encryption.key`：加密密钥
- `remember.json`：记住密码信息

## 安全说明

- 所有敏感数据使用Fernet对称加密算法（基于AES-128-CBC）加密存储
- 用户密码加密处理
- 自动生成和管理加密密钥
- 支持数据备份和恢复

## 常见问题

**Q: 系统启动时报错 "Could not find Qt platform plugin"**  
A: 这通常是由于Qt插件路径配置问题导致。可以尝试运行`run.py`脚本，它会尝试自动寻找正确的插件路径。

**Q: 如何备份我的密码数据？**  
A: 所有数据存储在`data`目录中。备份此目录即可保存所有数据。

**Q: 忘记密码怎么办？**  
A: 当前版本暂不支持密码恢复功能。请确保记住您的主密码。
